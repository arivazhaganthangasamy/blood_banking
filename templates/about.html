About LifeStream

A comprehensive Blood Donation Management System built for Chennai — connecting donors, patients, and blood banks in one powerful platform.

Project Overview

LifeStream is a full-stack web application using Flask & Python

LifeStream is designed to bridge the gap between blood donors and recipients in Chennai. It features a dual-role system — hospitals can manage and upload blood inventory, while users can register as donors or search for needed blood types. All data is stored securely in Excel sheets for easy management and reporting.

Key Features

🔐
Auth Module

Login & Sign Up

Secure authentication with role-based access for hospitals and individual users. Passwords are hashed using Werkzeug.

🏥
Hospital Module

Hospital Dashboard

Hospitals can upload blood availability by type, location and contact. View and manage their complete blood inventory.

🩸
Donor Module

Blood Donation

Users can register donations at any Chennai blood bank. System enforces the 8-week (56-day) rule between donations.

🔍
Search Module

Find Blood

Search available blood by type across 10+ Chennai blood banks. See contact numbers and locations instantly.

❤️
Wishlist Module

Wishlist System

Add blood banks to your wishlist when searching for specific blood types. Blood banks can monitor incoming requests.

📊
Data Module

Excel Storage

All donations, requests, wishlists and user data are stored in structured Excel sheets for transparency and reporting.
